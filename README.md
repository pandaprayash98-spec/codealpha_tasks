A web application built with React and Gemini AI.

[Open Website](YOUR_LIVE_VERCEL_LINK)

## Run Locally

### Prerequisites

* Node.js

### Installation

```bash
npm install
```

### Environment Variables

Create a `.env.local` file:

```env
GEMINI_API_KEY=your_gemini_api_key
```

### Start the App

```bash
npm run dev
```

The application will run locally at `http://localhost:5173`.
